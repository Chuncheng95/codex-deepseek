# Codex 通道切换器（Windows 版）

在 Windows 上双击一下，就能在 **DeepSeek 通道** 和 **GPT（ChatGPT 登录）通道** 之间来回切，
和 macOS 版是同一套逻辑。

## 运行环境

- Windows 10 或 Windows 11（64 位）。
- 系统自带 PowerShell 5.1，**不需要额外安装 Python、Node.js 或任何运行时**。
- 已安装 Codex 桌面版，并用 ChatGPT 账号登录过至少一次。
- Codex 客户端建议 0.144.0 或更新（`models.json` 的最低要求）。
- 自己的 DeepSeek API Key，一行，不加引号。
- 能访问 `api.deepseek.com`。切换动作本身不联网。
- 需要写入 `%USERPROFILE%\.codex` 的权限。

---

## 一、第一次使用（5 步）

1. **先填你自己的 API Key**：用记事本打开 `deepseek\deepseek-key.txt`，把你的 DeepSeek Key 粘到下一行，只留一行，不加引号。
   这个包本身不带 Key，必须自己填。

2. 把 **整个文件夹** 拷到 Windows（U 盘、网盘、微信传文件都行），解压到任意位置，比如 `D:\Codex-Switch`。
   不要只拷某一个文件，`CodexSwitch.ps1` 和 `deepseek\` 要在一起。

3. 先双击 **`环境检查.bat`**，它会检查 Windows 版本、PowerShell、Codex 配置目录和 Key 是否就绪。
   全部通过或只剩黄色提示时再继续。

4. **先完全退出 Codex / ChatGPT 应用**（右下角托盘里也退干净），然后双击 **`一键安装.bat`**。
   它会做三件事：
   - 把 `models.json`（模型目录）放到 `%USERPROFILE%\.codex\`
   - 把 `[model_providers.deepseek]` 段（含你的 API Key）写进 `%USERPROFILE%\.codex\config.toml`
   - 在桌面创建 3 个图标，并立刻切到 DeepSeek 通道

5. 重新打开 Codex 应用，在模型选择里应该能看到 **DeepSeek-Flash**。

---

## 二、日常使用

安装后，桌面上会有三个图标：

| 图标 | 作用 |
| --- | --- |
| **DS / 切到DeepSeek** | 切到 DeepSeek 通道 |
| **GPT / 切到GPT** | 切回 GPT 通道（ChatGPT 登录，DeepSeek 的配置留着但不再启用） |
| **⇄ / 一键切换模型** | 自动判断现在在哪边，切到另一边 |

切完 **完全退出并重新打开 Codex 应用** 才生效。

文件夹里还有几个备用按钮（安装后也会被复制到 `%USERPROFILE%\.codex\deepseek-switch\`）：

| 按钮 | 作用 |
| --- | --- |
| `查看当前通道.bat` | 只查看现在在哪条通道、Key 和模型目录的状态，不改任何文件 |
| `环境检查.bat` | 检查系统、PowerShell、Codex 配置和 Key 是否就绪，只读不改 |
| `恢复上次备份.bat` | 把 `config.toml` 恢复成最近一次切换前的样子 |
| `逻辑自检.bat` | 用样例文本跑一遍切换逻辑（不碰你的配置），有问题会红字提示 |
| `一键安装.bat` | 重新安装 / 更新脚本和桌面图标（换 Key 后也可以再跑一次） |

## 三、它到底改了什么

和你麦克上的做法一样，核心就是 `config.toml` 顶部的三行：

```toml
model = "deepseek-flash"
model_provider = "deepseek"
model_catalog_json = "C:/Users/你的用户名/.codex/models.json"
```

- **切到 DeepSeek**：确保这三行生效，并写入/刷新 `[model_providers.deepseek]` 段（base_url、wire_api、API Key）。
- **切到 GPT**：把这三行注释掉，变成 `# model = "deepseek-flash"` 这样；provider 段保留不删。
- **GPT 的 model 会被记住**：切到 DeepSeek 时，你原来的 `model = "gpt-5.6-sol"` 会被注释保存成
  `# model = "gpt-..."   # GPT 通道时自动恢复`，切回 GPT 时自动取消注释，来回切不丢设置。
- 每切一次都会备份，旧备份放在 `%USERPROFILE%\.codex\deepseek-switch-backups\`。

和麦克上不同的两点，都是刻意的：

1. **没有设置 `http_proxy`**。`api.deepseek.com` 在国内直连就行，硬写代理反而容易连不上。
   如果你的 Windows 是全局代理上网并且 DeepSeek 连不上，看一眼代理规则里是不是把 DeepSeek 也代理了。
2. **`model_catalog_json` 用绝对路径**（`C:/Users/...`），Windows 上不依赖 `~` 展开。

## 四、出问题怎么办

**双击后窗口一闪就没了 / 被拦**
Windows 可能把这个包当成「来自网络的文件」。右键解压出来的文件夹 → 属性 → 勾选「解除锁定」→ 确定，
再重新双击。另外 `.bat` 里已经带了 `-ExecutionPolicy Bypass`，一般不会再被脚本执行策略挡住。

**切换成功，但模型列表里没有 DeepSeek-Flash**
1. 确认 Codex 应用**完全退出后重新打开**了（不是只关窗口）。
2. 双击 `查看当前通道.bat`，看 `model` / `model_provider` / `model_catalog_json` 三行是否都在、且没有被 `#` 注释。
3. 客户端要够新（`models.json` 要求 ≥ 0.144.0），太旧的话升级一下 Codex 应用。

**DeepSeek 报 401 / 认证失败**
Key 不对或者额度没了。改 `%USERPROFILE%\.codex\deepseek-switch\deepseek\deepseek-key.txt`（只留一行 Key，别加引号），
然后双击一次「切到DeepSeek」——每次切换都会重读这个文件并刷新到配置里。

**想撤销这次改动**
双击 `恢复上次备份.bat`；或者手动编辑 `%USERPROFILE%\.codex\config.toml`，把那三行前面加 `#`。

**想彻底卸载**
在文件夹里用命令行跑 `powershell -ExecutionPolicy Bypass -File CodexSwitch.ps1 -Mode uninstall`，
它会注释掉那三行、移除 provider 段、删掉桌面图标。剩下的 `models.json` 和
`%USERPROFILE%\.codex\deepseek-switch\` 目录可以自己删。

---

## 五、安全提醒

填进 `deepseek\deepseek-key.txt` 的 Key、以及写进 `config.toml` 的 provider 段，都是**明文 API Key**。
这个包只在自己电脑之间传，别发到公开网盘、群聊或仓库里；万一泄露就去 DeepSeek 后台重新生成一个。
