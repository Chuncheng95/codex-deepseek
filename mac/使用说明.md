# Codex 切换工具（macOS）：两套方案

同一个功能，两种用法，任选一套。两套改的都是 `~/.codex/config.toml`，效果完全一样。

## 运行环境

- macOS 13 Ventura 或更新。
- 已安装 Codex 桌面版，并用 ChatGPT 账号登录过至少一次（这样 `~/.codex/config.toml` 才会存在）。
- 自己的 DeepSeek API Key，一行，不加引号。
- 能访问 `api.deepseek.com`。切换动作本身不联网。
- 需要写入 `~/.codex` 和 `~/.codex/deepseek-switch-backups` 的权限。
- **不需要 Python、Node.js 或任何额外运行时。**
- App 未做 Apple 公证，首次打开需要右键 → 打开放行一次。

## 方案 A：一键 App（推荐）

位置：`方案A-一键App/Codex Switch.app`

适合大多数人。双击 App，不打开终端，也没有黑框窗口。

1. 双击 `Codex Switch.app`。
2. 第一次打开会要求填入自己的 DeepSeek Key，粘贴后点“保存”。
3. 点“切到 DeepSeek”，等提示完成。
4. `⌘Q` 完全退出 Codex，再重新打开。
5. 模型列表里出现 **DeepSeek-Flash** 就成功了。

日常使用：

- 菜单栏常驻图标，点一下就能切。
- `⌘1` 切 DeepSeek，`⌘2` 切回 GPT。
- “恢复上次备份”可以一键回滚。
- 换 Key 后点“刷新 DeepSeek 配置”。

如果 macOS 提示“无法验证开发者”：右键点 App → 打开 → 再点一次“打开”，只需做一次。

## 方案 B：命令行

位置：`方案B-命令行/`

适合喜欢终端、远程 SSH，或者想自己看每一步改了什么的人。

1. 用文本编辑打开 `deepseek/deepseek-key.txt`，把自己的 Key 粘到下一行，只留一行，不加引号。
2. `⌘Q` 完全退出 Codex。
3. 双击 `一键安装.command`。
4. 重新打开 Codex，模型列表里选 **DeepSeek-Flash**。

文件夹里还有：

| 文件 | 作用 |
|---|---|
| `切到DeepSeek.command` | 切到 DeepSeek |
| `切到GPT.command` | 切回 GPT |
| `查看当前通道.command` | 只看状态，不改文件 |
| `恢复上次备份.command` | 回到上一次切换前 |

第一次运行 `.command` 如果被拦，右键 → 打开。

## 怎么选

- 不想看到终端：用方案 A。
- 想看清楚每一步、或者要远程操作：用方案 B。

两套可以共存，配置互通。但建议固定用一套，免得 Key 和备份分散在两处。

## 它改了什么

只动 `~/.codex/config.toml` 顶部的三行：

```toml
model = "deepseek-flash"
model_provider = "deepseek"
model_catalog_json = "/Users/你的用户名/.codex/models.json"
```

再加一段 DeepSeek provider。方案 A 会把内置的 `models.json` 自动装到 `~/.codex/`；方案 B 在安装时复制。

每次改动前都会备份到 `~/.codex/deepseek-switch-backups/`。

## 系统要求

- macOS 13 或更新。
- 已安装 Codex 桌面版，并用 ChatGPT 账号登录过一次。
- 自己有一个 DeepSeek API Key。

## 安全提醒

两套方案都不会上传 Key，也不会把 Key 写进日志。

但 Codex 本身要读取 Key 才能调用 DeepSeek，所以 `~/.codex/config.toml` 的 provider 段里会是明文。这个文件不要发给别人。
